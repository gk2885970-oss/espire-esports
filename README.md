# Espire Esports

Espire Esports is a competitive esports platform where players can join tournaments,
track leaderboards, and compete in games like BGMI and Free Fire.

## Features
- Tournament Management
- Live Leaderboard
- Team Registration
- Match Result System

## Technology
- Frontend: Vite + TypeScript
- Backend: Node.js
- Database: SQLite
